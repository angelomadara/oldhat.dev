About oldhat.dev

oldhat.dev is a personal project that exposes a live view of what an internet-facing server encounters every day. Every incoming HTTP request is categorised by threat class — .git directory traversal, .env credential theft, WordPress vulnerability scanning, SQL injection attempts, admin panel brute-force, and configuration file leaks — alongside geographic origins and traffic type breakdowns.

The FastAPI backend and Alpine.js frontend serve this data with full history browsable by date. The goal is simple: show exactly what attacks a typical internet-facing server faces — no filters, no sanitised demo data, just the raw reality of the modern web.

The code is open-source.
