How categories are assigned

Each tile counts requests whose path matches a known attack pattern. .env and config leak cover credential and configuration harvesting — /.env, /config.json, /.aws/credentials. git covers /.git/ directory traversal. wordpress and admin_scan cover CMS and login-panel probing, and sqli covers SQL injection payloads in the query string. Anything that matches no known signature is counted as other.
