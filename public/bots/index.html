Reading this table

A user-agent claiming many hits from a single IP is usually one host running a script, while the same name spread across many IPs suggests a distributed crawler or a fleet of cloud workers. Well-behaved search engines identify themselves; scanners frequently spoof or omit the user-agent entirely, which is why generic library names like Python-requests and curl appear near the top.
